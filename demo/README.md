# Team Analyzer demo assets

The live demo is the full-stack application in `frontend/`, served with the Spring Boot API from `backend/` through Vercel Services (see the root [`vercel.json`](../vercel.json)).

This directory contains the earlier static portfolio mock-up. Its fictional content is not connected to the database and it is no longer the Vercel project root. The sample participant flow keeps answers in page memory only.

To look at it locally, open `index.html` in a browser or serve the directory with any static file server:

```bash
npx serve demo
```

The source repository is [fabsGitHub/team-analyzer-portfolio](https://github.com/fabsGitHub/team-analyzer-portfolio).
